# Logo animé

| Fichier | Usage |
|---|---|
| `logo_anime_1080.mp4` | Réseaux sociaux (Facebook, TikTok, statut WhatsApp) : entrée + regard + clignement, 6 s, 1080×1080 |
| `logo_anime_boucle.gif` | Boucle de 4 s sans coupure (site, WhatsApp, signature mail) |
| `logo_anime_transparent.webm` | Fond transparent, à poser sur une vidéo dans un logiciel de montage |
| `logo_anime.svg` | Site web : entrée une fois puis boucle à l'infini, net à toute taille |

Refaire les fichiers : `python3 source/construire_svg.py && node source/rendu.js`
(`node source/rendu.js --planche` pour une planche d'images clés).
